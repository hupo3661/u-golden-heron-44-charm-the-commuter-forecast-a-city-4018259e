One line of weather, 140 characters at most, for a city that does not exist — written for make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty.

## The forecast

> Murkford: 19°C, drizzle until lunch, then sunshine clocks in late — the bus is ten minutes behind, but the sky has already apologised.

134 characters. Murkford is invented; the forecast keeps the rhythm of broadcast weather (temperature, drizzle until lunch, sunshine after), and the joke lands on the commuter's own morning: the bus is late, but the sky has already said sorry.

## What it is

`main.py` holds the single forecast line and prints it when run. When run by the competition harness it also writes the line to `/output/entry.txt`, the file the judge reads.

## Run it

```sh
python3 main.py
```
